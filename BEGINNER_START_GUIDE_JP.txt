JARVIS 初心者向け完全起動・接続ガイド
========================================

この説明書は、USB内のJARVISを使って、Android、Windows、Mac/Linux、iPhoneを親機または子機として使うための手順です。

最初に知っておくこと
----------------------

- 親機: AI本体、記憶、JARVISサーバーが動く端末
- 子機: 親機のJARVISをブラウザから使う端末
- USBを挿しただけでは安全のため自動実行しません
- 初回だけ、親機にファイルをコピーして起動操作が必要です
- USBは抜く前に、必ずJARVISを停止してください
- APIトークンや接続コードは他人に見せないでください

USBの中で最初に見る場所
------------------------

RELEASES/JARVIS_SC56B_Starter/

主なファイル:
- android/termux_setup.sh                 Android初回セットアップ
- android/START_JARVIS_RELAY_ANDROID.sh  Android親機・中継サーバー起動
- START_JARVIS.bat                        Windows簡単起動
- START_JARVIS.sh                         Mac/Linux簡単起動
- relay_server.py                         JARVIS独自中継サーバー
- relay_client.py                         親機用中継クライアント
- models/model.gguf                       オフラインAIモデル
- MANUAL/                                  詳細説明書

============================================================
1. Androidを親機にする
============================================================

必要なもの:
- Android端末
- USBメモリをAndroidへ接続する変換アダプター
- Termux
- USBの空き容量約2GB以上

注意: Androidでは、USBメモリ内のプログラムを直接実行しません。まずJARVISフォルダをAndroid本体へコピーします。

A. USBを接続してコピーする

1. USBメモリをAndroidへ接続します。
2. ファイル管理アプリを開きます。
3. USBメモリを開きます。
4. RELEASES/JARVIS_SC56B_Starter/を探します。
5. フォルダ全体をAndroid内部ストレージへコピーします。
6. コピー先を次の名前にすると分かりやすいです。

   内部ストレージ/JARVIS/

7. コピーが終わるまでUSBを抜かないでください。

B. Termuxを準備する

1. Termuxを起動します。
2. 初回にストレージ許可を求められたら許可します。
3. 次のコマンドを1行ずつ入力します。

   termux-setup-storage

4. Androidの許可画面が出たら「許可」を押します。
5. JARVISフォルダへ移動します。

   cd ~/storage/shared/JARVIS

6. フォルダが見つからない場合は、ファイル管理アプリでコピー先を確認してください。

C. 初回セットアップ

次を実行します。

   bash android/termux_setup.sh

この処理が行うこと:
- 必要なPythonパッケージを準備
- JARVISの保存場所を作成
- Qwen3-1.7BオフラインAIを確認
- Androidで実行できる基本環境を準備

モデルがUSBからコピーされていれば、再ダウンロードは基本的に行いません。

D. Androidを親機として起動する

次を実行します。

   bash android/START_JARVIS_RELAY_ANDROID.sh

初回起動時に自動で行われること:
- 中継トークンをランダム生成
- 子機用接続コードを生成
- 設定ファイルを作成
- JARVIS本体を起動
- 中継サーバーを起動
- 中継クライアントを起動
- Androidのスリープを防止

画面に表示された以下をメモします。
- 子機用接続コード
- 中継トークンの保存場所
- SC-56BのIPアドレス

E. Android親機のIPアドレスを確認する

同じWi-Fiの子機から使う場合、Termuxで次を実行します。

   ip addr show wlan0

「192.168.x.x」または「10.x.x.x」のようなアドレスを探します。

例:
   192.168.1.25

子機のブラウザで次を開きます。

   http://192.168.1.25:8765/

中継画面を使う場合は次です。

   http://192.168.1.25:9000/client

F. Android親機を停止する

Termuxで次を実行します。

   pkill -F ~/.jarvis/jarvis.pid
   pkill -F ~/.jarvis/relay-client.pid
   pkill -F ~/.jarvis/relay.pid

または、Termux画面でCtrl+Cを押します。

============================================================
2. Windowsを親機にする
============================================================

A. USBからコピーする

1. USBメモリをWindows PCへ接続します。
2. USBメモリを開きます。
3. RELEASES/JARVIS_SC56B_Starter/をPCのデスクトップなどへコピーします。
4. コピーが完了してからUSBを抜きます。

B. 初回セットアップ

1. JARVISフォルダを開きます。
2. START_JARVIS.batを右クリックします。
3. 「管理者として実行」ではなく、まず通常のダブルクリックを試します。
4. Windows Defenderが確認した場合は、ファイルの場所を確認してから許可します。
5. 黒い画面が開き、必要な準備が行われます。

C. Windows親機の起動

通常は次をダブルクリックします。

   START_JARVIS.bat

同じWi-Fiの子機から使う場合:

1. Windowsキーを押します。
2. 「cmd」と入力してコマンドプロンプトを開きます。
3. 次を入力します。

   ipconfig

4. 「IPv4 Address」の値を確認します。

例:
   192.168.1.40

5. 子機のブラウザで次を開きます。

   http://192.168.1.40:8765/

Windowsファイアウォールが表示されたら、プライベートネットワークでの通信だけを許可します。パブリックネットワークの許可は、必要性を確認してからにしてください。

D. Windowsで中継サーバーを使う

コマンドプロンプトでJARVISフォルダへ移動します。

   cd C:\Users\あなたの名前\Desktop\JARVIS_SC56B_Starter

中継サーバーを起動します。

   set JARVIS_RELAY_TOKEN=長いランダム文字列
   uvicorn relay_server:app --host 0.0.0.0 --port 9000

別のコマンドプロンプトでJARVIS本体を起動します。

   START_JARVIS.bat

子機用画面:

   http://WindowsのIPアドレス:9000/client

D. Windows親機を停止する

JARVISを起動している黒い画面でCtrl+Cを押します。中継サーバーも別画面で起動している場合は、そちらでもCtrl+Cを押します。

============================================================
3. MacまたはLinuxを親機にする
============================================================

A. USBからコピーする

1. USBメモリをMacまたはLinux PCへ接続します。
2. RELEASES/JARVIS_SC56B_Starter/をホームフォルダへコピーします。
3. USBを安全に取り外します。

B. 初回セットアップ

ターミナルを開き、JARVISフォルダへ移動します。

   cd ~/JARVIS_SC56B_Starter

実行権限を付けます。

   chmod +x START_JARVIS.sh
   chmod +x android/*.sh

初回セットアップを実行します。

   bash android/termux_setup.sh

MacではTermux用セットアップが使えない場合があります。その場合は、Python 3を準備し、次を実行します。

   python3 -m pip install -r requirements.txt
   python3 START_JARVIS.py

C. Mac/Linux親機を起動する

   bash START_JARVIS.sh

同じWi-FiのIPアドレスを確認します。

Linux:
   hostname -I

Mac:
   ipconfig getifaddr en0

子機のブラウザ:

   http://確認したIPアドレス:8765/

中継画面:

   http://確認したIPアドレス:9000/client

D. 停止する

JARVISを実行しているターミナルでCtrl+Cを押します。

============================================================
4. iPhoneを親機にする
============================================================

iPhoneはUSBのファイルを直接実行できません。IPAをiPhoneへインストールする初回操作には、PCと署名が必要です。

A. IPAを準備する

1. USB内のIPAをPCへコピーします。
2. Sideloadlyなど、ユーザーが選んだ署名方法でIPAをiPhoneへインストールします。
3. Apple IDと署名に関する入力は、ユーザー自身がPC上で行います。
4. iPhoneで「設定→一般→VPNとデバイス管理」を開き、必要な開発者確認を行います。

B. iPhone親機を起動する

1. JARVISアプリを開きます。
2. マイクを使う場合はマイク許可を許可します。
3. 音声認識を使う場合は音声認識許可を許可します。
4. 「起動」を押します。
5. 入力を文字または音声に設定します。
6. 出力を文字または音声に設定します。

C. iPhone親機を子機から使う

iPhoneと子機が同じWi-Fiにいる場合、アプリ画面に表示された親機アドレスを子機のSafariまたはChromeで開きます。

同じWi-Fi以外で使う場合は、iPhone回線やルーターが外部着信を許可している必要があります。携帯回線のCGNATにより、外部から接続できない場合があります。

============================================================
5. 子機として使う方法
============================================================

子機には専用アプリを入れず、SafariまたはChromeを使えます。

同じWi-Fiの場合:

   http://親機のIPアドレス:8765/

独自中継サーバー画面の場合:

   http://中継サーバーのアドレス:9000/client

画面を開いたら:
1. 接続コードを入力
2. 中継トークンを入力
3. JARVISへ文章を入力
4. 送信を押す

音声入力を使う場合:
1. 入力方式を「音声」にする
2. 音声入力開始を押す
3. マイク許可を許可する
4. 話し終わると送信する

音声出力を使う場合:
1. 出力方式を「音声」にする
2. JARVISの回答が端末の音声で読み上げられる

============================================================
6. 同じWi-Fiではない場所から使う
============================================================

外出先から使うには、次のどちらかが必要です。

方法A: SC-56Bを外部公開する
- 自宅Wi-Fiルーターのポート転送
- 固定IPまたはDDNS
- HTTPS
- 強力なトークン

方法B: SC-56B自身を中継サーバーにする
- SC-56Bへ外部から到達できる回線
- 9000番ポートへの接続
- HTTPS推奨

携帯回線ではCGNATにより外部から接続できない場合があります。この制限はUSBやJARVISだけでは解除できません。

絶対に、認証なしでJARVISをインターネットへ公開しないでください。

============================================================
7. よくある問題
============================================================

「モデルがありません」:
- models/model.ggufがあるか確認
- USBからJARVISフォルダを完全にコピーしたか確認
- 空き容量が約2GB以上あるか確認

「llama.cppがありません」:
- Androidではtermux_setup.shをもう一度実行
- PCではllama.cppの実行ファイルをJARVIS_LLAMA_BINで指定

「子機から開けない」:
- 親機のJARVISが起動中か確認
- IPアドレスが正しいか確認
- 子機と親機が同じWi-Fiか確認
- Windowsファイアウォールを確認
- 8765番または9000番ポートを確認

「外出先から開けない」:
- 親機の携帯回線がCGNATではないか確認
- ルーターのポート転送を確認
- HTTPSと公開アドレスを確認
- JARVISがスリープで停止していないか確認

「音声入力できない」:
- SafariまたはChromeのマイク許可を確認
- iPhoneまたはAndroidのマイク許可を確認
- HTTPSまたはlocalhostが必要なブラウザ仕様の場合があります

============================================================
8. セキュリティ
============================================================

- 接続コードとトークンを他人に渡さない
- GitHubやSNSへ設定ファイルをアップロードしない
- APIキーやApple IDパスワードをUSBへ保存しない
- 使わないときはJARVISと中継サーバーを停止
- 外部公開時はHTTPSを使う
- 不審な端末からの接続があったらトークンを再生成
